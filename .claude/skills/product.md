# Product

When working on product tasks:

## User Stories
- Write from the user's perspective
- Include acceptance criteria
- Link to designs or mockups when available
- Consider edge cases and error states

## Documentation
- Update user-facing docs with feature changes
- Write clear error messages that help users recover
- Document API changes in changelogs
- Keep README current with setup instructions

## Feature Flags
- Use feature flags for gradual rollouts
- Clean up flags after full rollout
- Document flag behavior and cleanup timeline

## Analytics
- Track meaningful user actions, not vanity metrics
- Respect user privacy — anonymize where possible
- Document what each event means and when it fires
